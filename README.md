# Robot Hexápodo - Página web

Página web informativa del proyecto robot hexápodo.
Hecha con HTML, CSS y JavaScript (sin frameworks).

## Archivos

```
index.html            Inicio
mision-vision.html    Misión, visión, valores y equipo
proyecto.html         Cómo funciona el robot
contacto.html         Formulario de preguntas
boceto.html           Boceto digital de la página
styles.css            Estilos
app.js                Menú del celular, botón para subir, demo de caminar y formulario
favicon.ico           Ícono de la pestaña del navegador
assets/               Logo (logo.png y logo-header.png) e ilustraciones
```

## Cómo verla

Abrir `index.html` con doble clic en el navegador.

## Colores

- Rosas: #FFC0CB, #eebbbb, #f6c8c7, #f9d6d5, #fbe3e3, #fdf1f1
- Verdes (solo viñetas y detalles): #88DC65, #93E46F, #80D85B
- Texto: #3b2a2d (café oscuro, para que se pueda leer sobre el rosa)

## Tipografías (Google Fonts)

- Títulos: Poppins
- Texto: Open Sans
- Subtítulos y nombres: Quicksand

Las letras se cargan desde Google Fonts, por eso se necesita internet para verlas.
Sin internet se ve Arial.

## Notas

- El formulario de contacto no envía mensajes a ningún lado, es solo de muestra.
- Las imágenes de `assets/` se pueden cambiar por fotos reales del robot (mismo nombre o cambiando el `src` en el HTML).
